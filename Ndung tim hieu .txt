============================3. tạo Engine===========================
Nếu Jetson đã có TensorRT và trtexec:

bash
/usr/src/tensorrt/bin/trtexec \
  --onnx=models/model.onnx \
  --saveEngine=models/model_fp16.engine \
  --fp16
Kiểm tra engine:

bash
/usr/src/tensorrt/bin/trtexec \
  --loadEngine=models/model_fp16.engine
Chỉ định kích thước input nếu mô hình dynamic shape:

bash
/usr/src/tensorrt/bin/trtexec \
  --onnx=models/model.onnx \
  --saveEngine=models/model_fp16.engine \
  --fp16 \
  --minShapes=images:1x3x320x320 \
  --optShapes=images:1x3x640x640 \
  --maxShapes=images:1x3x640x640
Tên images phải đúng với tên input của file ONNX. Có thể xem thông tin bằng:

bash
trtexec --onnx=models/model.onnx --verbose
Tên đường dẫn trtexec có thể khác tùy JetPack:

bash
which trtexec
find /usr -name trtexec 2>/dev/null




==============Điểm khác biệt giữa FP16 và INT8=====
FP32
Dễ tương thích.

Chính xác thường tốt.

Chậm và tốn bộ nhớ hơn.

FP16
Thường là lựa chọn đầu tiên trên Jetson.

Nhanh hơn FP32.

Ít ảnh hưởng đến độ chính xác trong nhiều mô hình.

Lệnh:

bash
trtexec \
  --onnx=model.onnx \
  --saveEngine=model_fp16.engine \
  --fp16
INT8
Có thể nhanh và nhẹ hơn FP16.

Cần calibration dataset.

Có nguy cơ giảm độ chính xác nếu calibration kém.

Không nên bật INT8 ngay khi bạn chưa có baseline FP32/FP16. Hãy làm theo thứ tự:

text
FP32 chạy đúng
→ FP16 chạy đúng
→ INT8 nếu cần tối ưu thêm

11. Dùng script triển khai
Tạo deploy.sh trên laptop:

bash
#!/usr/bin/env bash

set -e

TARGET="jetson@192.168.1.50"
REMOTE_DIR="/home/jetson/my_project"

rsync -avz --progress \
  --exclude ".git" \
  --exclude ".venv" \
  --exclude "__pycache__" \
  --exclude "data" \
  ./ "$TARGET:$REMOTE_DIR/"

ssh "$TARGET" "
  cd $REMOTE_DIR &&
  chmod +x build_engine.sh &&
  ./build_engine.sh &&
  python3 src/inference.py
"
Tách script build engine trên Jetson:

bash
#!/usr/bin/env bash

set -e

ENGINE="models/model_fp16.engine"
ONNX="models/model.onnx"

if [ ! -f "$ENGINE" ]; then
  /usr/src/tensorrt/bin/trtexec \
    --onnx="$ONNX" \
    --saveEngine="$ENGINE" \
    --fp16
fi
Sau đó chạy từ laptop:

bash
bash deploy.sh

14. Lỗi thường gặp
Lỗi	Nguyên nhân có thể	Cách xử lý
Permission denied khi SSH	Sai user, mật khẩu hoặc SSH chưa bật	Kiểm tra user, IP, sudo systemctl status ssh
No route to host	Laptop và Jetson khác mạng	Kiểm tra IP, Wi-Fi/Ethernet, ping
Engine không deserialize	Sai TensorRT, GPU hoặc nền tảng	Build lại engine trên Jetson
Unsupported operator	ONNX có toán tử chưa được TensorRT hỗ trợ	Simplify ONNX, dùng plugin hoặc đổi export
Out of memory	Mô hình/input quá lớn	Giảm input, dùng FP16, giảm batch
FPS thấp	CPU tiền xử lý/hậu xử lý là nút thắt	Đo từng giai đoạn, tối ưu copy CPU-GPU
Kết quả sai	Sai RGB/BGR, shape hoặc normalize	So sánh từng bước với pipeline gốc
Chạy được nhưng chậm	Engine build ở chế độ không phù hợp	Build lại trên Jetson, thử FP16 và benchmark
